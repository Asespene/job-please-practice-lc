# Templates Guide

This folder contains reusable Python 3 code skeletons so you never waste interview time reinventing boilerplate:

- [`solution_template.py`](solution_template.py): Copy this file (or run `python3 scripts/new_problem.py`) when starting any new LeetCode problem.
- [`algorithms.py`](algorithms.py): Production-ready, tested implementations of the 8 most common building blocks:
  1. **Binary Search on Answer Space** (`binary_search_first_true`)
  2. **Variable Sliding Window** (`sliding_window_template`)
  3. **Monotonic Stack** (`next_greater_indices`)
  4. **2D Grid Shortest-Path BFS** (`grid_bfs`)
  5. **Kahn's Topological Sort** (`topological_sort`)
  6. **Disjoint Set Union / Union-Find** (`UnionFind`)
  7. **Dijkstra's Shortest Path** (`dijkstra`)
  8. **Prefix Tree / Trie** (`Trie`)
